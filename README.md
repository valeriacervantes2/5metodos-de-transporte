# 5 Métodos de Transporte
Aplicación de escritorio (Tkinter) para resolver problemas de transporte paso a paso:
Esquina Noroeste, Costo Mínimo, Vogel (`miguel.py`), Banquillo y DIMO/MODI, más una comparativa final.

    python main.py                            # ejecutar la aplicación
    python -m pruebas.test_metodos           # pruebas

En Linux, si falta Tkinter: `sudo apt install python3-tk`.
